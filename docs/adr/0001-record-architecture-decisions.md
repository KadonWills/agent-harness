# ADR-0001: Record architecture decisions

Status: Accepted

## Context
Significant technical decisions need durable rationale, especially in an
OSS project where contributors weren't present for the discussion.

## Decision
We record architecturally significant decisions as short ADRs in
`docs/adr/`, numbered sequentially, using this template: Context,
Decision, Consequences. Superseded ADRs are marked, never deleted.

## Consequences
Contributors can trace "why is it like this" without archaeology.
Proposals to reverse a decision reference the ADR they supersede.
