# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, no harassment of any kind.
Technical disagreement is welcome; contempt is not. This applies in
issues, PRs, Discussions, and any project space.

Reports: contact a maintainer listed in [MAINTAINERS.md](MAINTAINERS.md)
privately — via their GitHub profile contact details, or by opening a
[private security advisory](https://github.com/KadonWills/agent-harness/security/advisories/new)
if you would rather not use email. Reports are handled confidentially by maintainers not
involved in the incident. Consequences follow the Covenant's enforcement
ladder: correction → warning → temporary ban → permanent ban.
